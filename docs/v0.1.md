# cueio 0.1.0 (Tauri): o que o app fazia

A primeira versão do cueio (antes chamado Mantis) foi feita em Tauri e teve o código-fonte perdido.
Esta spec foi reconstruída a partir do frontend embutido no binário instalado (build de 13/07/2026)
e serviu de base para a reescrita nativa da versão 0.2.

## Stack original

- Tauri v2 (Rust) + React 19 + Vite
- Ícones: Hugeicons
- Markdown: `marked` (GFM, `breaks: true`) + DOMPurify, carregados sob demanda
- Plugin dialog do Tauri (abrir, salvar, confirmar)

## Funcionalidades

- **Abas** de documentos: nova (⌘T), fechar (⌘W, clique do meio), trocar (⌃Tab / ⌃⇧Tab, ⌘1...⌘9, ⌘9 = última), reordenar arrastando, ponto indicando alteração não salva.
- **Arquivos**: abrir (⌘O), salvar (⌘S), salvar como (⌘⇧S). Filtro "Markdown e texto": `md, markdown, mdown, mkdn, txt, text`.
- Abrir um arquivo que já está aberto foca a aba existente. Abrir com uma aba vazia e intocada reaproveita essa aba.
- Documento novo: "Sem título.md", "Sem título 2.md"... (nome sugerido ao salvar: `sem-titulo-2.md`).
- **Modos**: Raw (textarea monoespaçada) e Preview (markdown renderizado). Arquivos `.md` abrem em Preview, `.txt` só em Raw. Enquanto o preview renderiza, mostra o texto cru (`quick-preview`).
- **Proteção contra perda**: confirmação ao fechar aba com alterações; o backend recebe a contagem de documentos não salvos e bloqueia o fechamento do app.
- **Associação de arquivos** no Finder (Abrir com / duplo clique) para `.md` e `.txt`. Arquivos chegam via evento `open-documents` + comando `take_pending_documents`.
- **Barra de status**: caminho ou mensagem à esquerda; "Salvo ✓ / Editado / Não salvo / Processando / Preparando preview" à direita.
- Título da janela: `cueio | <nome>`.

## Comandos do backend (Rust)

| Comando | Função |
| --- | --- |
| `read_document(path)` | lê arquivo, retorna `{ name, path, extension, content }` |
| `write_document(path, content)` | grava e retorna o mesmo shape |
| `set_unsaved_document_count(count)` | alimenta a proteção de fechamento |
| `take_pending_documents()` | arquivos recebidos do Finder antes do frontend carregar |

## Visual

- Barra de título transparente com semáforos nativos (padding esquerdo de 90px), toolbar de 42px + linha de abas de 38px, status bar de 24px.
- Abas em pílula (`border-radius: 999px`), até 220px, ativa com fundo `--control` e sombra leve.
- Switch Raw/Preview em pílula com thumb deslizante. Tooltips com atalho em `<kbd>`.
- Tipografia: Inter / SF para UI em 13px; SF Mono 13px, line-height 1.65 no editor; preview em 15px estilo GitHub.
- Tokens claro: `bg #fafafa`, `text #1f1f1f`, `muted #737373`, `line #e5e5e5`, `control #f1f1f1`, `accent #0969da`.
- Tokens escuro: `bg #111`, `text #ededed`, `muted #a3a3a3`, `line #2b2b2b`, `control #202020`, `accent #58a6ff`.
- Easing: `--ease-out: cubic-bezier(.23,1,.32,1)`, `--ease-in-out: cubic-bezier(.77,0,.175,1)`.
